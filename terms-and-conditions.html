3. Description of Easy QR

Easy QR is a free app that lets you:

  • scan QR codes and supported barcodes (QR, Aztec, Data Matrix, PDF417, EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, ITF, Codabar) with the camera or from a photo;
  • create QR codes for websites, text, Wi-Fi networks, contacts and email, and Code 128, EAN-13, EAN-8, UPC-A and Code 39 barcodes;
  • keep an optional history on your device, and save, share or copy codes and their content.

Easy QR has no accounts, subscriptions or in-app purchases. Scanning and code creation work offline. The app is supported by advertising.
